2. 이 제출본에서 변경한 부분
- 0.2.5 소스에 fixed-test4까지의 수정 사항을 반영한 제출 빌드.
  제공받은 0.2.7 APK의 소스 코드를 복원한 버전은 아님.
- 제출 패키지·앱 이름·버전과 전용 서명 설정 추가.
- 키가 없으면 디버그 키로 대신 서명하던 동작 제거.
  서명 설정이 없는 실제 assembleRelease 실행이 requireReleaseSigning에서
  중단되는 것을 확인한 뒤 개인 설정을 복원함.
- 검증 패키지와 제출 패키지를 동시에 선택하지 못하도록 제한.
- 제출 패키지에서 강제 시연 빌드를 허용하지 않음.
- 기존 앱의 운영 코드·리소스 64개는 fixed-test4와 바이트 단위로 동일.
  이번 작업은 앱 기능을 새로 바꾸는 대신 배포 설정과 전달 문서를 정비함.
